Como funciona

  1. Digite o username

    Qualquer perfil público do GitHub. Nada é armazenado.

  2. Veja a cidade acender

    Os últimos 365 dias viram doze casas, uma por mês.

  3. Baixe em PNG

    1500×500 para o X, 1584×396 para o LinkedIn.

Como ler a cidade

  • Cada casa é um mês — doze casas, os últimos doze meses, da esquerda para a direita.
  • Cada janela é um dia, em ordem: de cima para baixo, coluna a coluna.
  • O brilho é a quantidade de contribuições do dia, na mesma escala de verdes do gráfico do GitHub.
