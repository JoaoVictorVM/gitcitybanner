How to read the city

  1. One house, one month

    Every house is a month — twelve houses, the last twelve months, left to right.

  2. One window, one day

    Every window is a day, in order: top to bottom, column by column.

  3. More light, more contributions

    Brightness is the day's contribution count, on the same green scale as the GitHub graph.

How it works

  1. Type the username

    Any public GitHub profile. Nothing is stored.

  2. Watch the city light up

    The last 365 days become twelve houses, one per month.

  3. Download as PNG

    1500×500 for X, 1584×396 for LinkedIn.
